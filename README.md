# Hi, I'm Tristan

**Domains, DNS & email · Self-hosting · Web projects**

I work with domains, DNS and email routing. Outside that, I build and run my own web projects — from practical tools to a multiplayer browser game.

I like understanding what happens underneath: why an email gets rejected, where a piece of data comes from, or what happens when a service fails.

### What I work with

- **Domains & email:** DNS, mail routing, SPF, DKIM, DMARC and MTA-STS.
- **Running things:** Docker, Coolify, Traefik and Cloudflare.
- **Building things:** TypeScript, JavaScript, React, Node.js and PostgreSQL.
